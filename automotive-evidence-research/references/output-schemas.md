# Output Schemas

## Fact card

| Field | Content |
|---|---|
| Claim | One testable statement |
| Evidence state | Confirmed / High-confidence inference / Unknown |
| Value and unit | Preserve original and normalized value |
| Conditions | Version, date, geography, test condition |
| Sources | Direct links with source grade |
| Independence | Independent / common origin / unclear |
| Conflict | Competing value or interpretation |
| Limitation | What the evidence does not establish |

## Evidence matrix

| ID | Claim | Source A | Source B | Independence | State | Gap |
|---|---|---|---|---|---|---|

## Image evidence record

| Field | Content |
|---|---|
| Figure ID | Stable report identifier |
| Type | Photo/render/patent/diagram/chart/redraw |
| Visible facts | Direct observations |
| Inferences | Reasoned interpretation |
| Unknowns | Occluded or unsupported structure |
| Provenance | Publisher, title, URL, date, page/figure |
| Rights | Permitted/restricted/unclear/review |
| Edits | Crop/annotation/translation/redraw |
| Supported claims | Claim IDs |

## Concise conclusion

Lead with confirmed facts, then high-confidence inference, then unknowns and conflicts. Keep recommendations separate and include them only when the user requests them.
